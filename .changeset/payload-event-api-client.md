New package: a client for the public Eventuras event API (list events, read one), with the package's own types, and a Payload block that lists events and links to their pages on the Eventuras site. The plugin adds the block to the `story` field of the collections named. Events carry their `uuid` as well as the numeric id, and `events.get` takes either.
